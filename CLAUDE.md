# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Статус проекта

Этап 0 (контент-движок) **задеплоен на shiny-ru** (`/opt/ai-invest`, cron 05:30 UTC = 08:30 МСК → `run-morning`): сборщики MOEX/ЦБ, дайджест через OpenRouter, автопост в Telegram-канал [@InvestDigestAI](https://t.me/InvestDigestAI). Поддержан также мессенджер MAX (`publish.py` постит во все настроенные площадки; MAX_* в `.env` пока пустые — ждём бота от @MasterBot). Деплой = tar+scp файлов в `/opt/ai-invest` + `docker compose build worker` (см. историю: git-remote на сервере нет).

Этап 1 (web): `web/` — **Next.js 16** (App Router, Turbopack, Tailwind v4; ⚠️ есть breaking changes против 15 — см. `web/node_modules/next/dist/docs/`). Страницы: `/`, `/digest`, `/digest/[date]`, `/stocks`, `/stocks/[secid]`, `/login`, `/watchlist` + API-роуты auth/watchlist. Данные напрямую из Postgres (`postgres.js`; колонки `date` кастовать `::text` в SQL — клиент отдаёт их как JS Date). Конфиг — `web/.env.local`. Команды: `npm run dev` / `npm run build` / `npm run start` из `web/`.

**Auth** — без пароля, через deep-link Telegram-бота `@AI_helper_invest_ru_bot`: сайт создаёт `login_tokens` → юзер жмёт Start у бота → бот (worker `run-bot`, compose-сервис `bot`) подтверждает токен → `/api/auth/poll` выдаёт cookie-сессию (`sessions`). Watchlist редактируется и на сайте, и в боте (/add, /del, /list); персональные дайджесты шлются в `run-morning` после канального.

**Прод на shiny-ru** (`/opt/ai-invest`): compose-сервисы `postgres` (без портов), `web` (loopback `127.0.0.1:3020`), `bot` (long polling), `worker` (one-shot, cron). Хостовый nginx: `/etc/nginx/sites-available/investdigestai.conf` → proxy на 3020. Домен: **https://investdigestai.ru** — живой (A-записи + LE-сертификат через certbot с авто-продлением, http→https редирект).

## Команды (worker)

```powershell
docker compose up -d                  # локальный Postgres (127.0.0.1:5441, pgvector/pg16)
cd worker
uv sync                               # зависимости (.venv)
uv run ai-invest init-db              # создать таблицы (пока create_all, без alembic)
uv run ai-invest sync-securities      # справочник бумаг TQBR
uv run ai-invest collect --date YYYY-MM-DD   # итоги торгов + индексы + курсы + ставка
uv run ai-invest digest --date YYYY-MM-DD [--post]  # сгенерировать дайджест (--post — в TG-канал)
uv run ai-invest run-morning          # полный цикл за вчера (для cron на сервере)
```

Конфиг — `worker/.env` (см. `.env.example`). Тестов пока нет; проверка — прогон команд на реальных API (MOEX ISS и ЦБ доступны без ключей).

## Деплой

Целевой сервер — **RU `85.239.41.235`** (shiny-ru, описан в глобальном CLAUDE.md). Там хостовый nginx на 80/443, ufw активен (default deny). Правила: контейнеры приложения бинжить **только на loopback** (как соседние 3001/3010/3011), новые порты в ufw не открывать — worker'у нужен только исходящий трафик; web (этап 1) выводить через хостовый nginx новым server-блоком. `run-morning` запускать cron'ом ~08:30 МСК.

## Продукт

ИИ-помощник по инвестициям на рынке РФ. Монетизация — web-приложение (подписка), мобильное приложение рассматривается на следующем этапе. Язык интерфейса и контента — русский.

Ядро ценности (три источника сигналов, которые продукт агрегирует и объясняет пользователю):
1. **События рынка** — новости, отчётности, дивиденды, решения ЦБ по ставке, санкционные/регуляторные события → как они влияют на конкретные бумаги.
2. **Ходы сильных игроков** — раскрытие информации (существенные факты, сделки инсайдеров и мажоритариев), ребалансировки крупных БПИФ/УК, публичные стратегии авторов (например, стратегии автоследования Тинькофф/БКС, портфели популярных авторов Пульса/Смартлаба).
3. **ИИ-синтез** — LLM собирает из (1) и (2) персонализированные идеи под профиль пользователя (риск, горизонт, ИИС/брокерский счёт) и объясняет логику простым языком. Объяснимость — ключевой дифференциатор, не «чёрный ящик».

### Источники данных (рынок РФ)

- **MOEX ISS API** (`iss.moex.com`) — котировки, свечи, индексы, дивиденды; бесплатный REST, базовый источник маркет-даты. Реалтайм требует платной подписки, отложенные данные (15 мин) бесплатны.
- **ЦБ РФ** (`cbr.ru`) — ключевая ставка, курсы валют, XML/API.
- **e-disclosure.ru / disclosure.skrin.ru** — существенные факты эмитентов, сделки инсайдеров.
- **СмартЛаб, БКС, Тинькофф Пульс** — настроения и публичные портфели (парсинг/API там, где допустимо ToS).
- Брокерские API для будущей интеграции портфелей: **Tinkoff Invest API** (gRPC, лучший DX), Finam Trade API, Алор.

### Юридическое ограничение (критично)

Персональные инвестиционные рекомендации в РФ — лицензируемая деятельность (инвестсоветник в реестре ЦБ, 39-ФЗ ст. 6.1–6.2). Пока статуса нет, продукт формулируется как **аналитика и информирование**, не «купи X»: дисклеймеры «не является ИИР» обязательны во всех выводах ИИ, в UI и в оферте. Это влияет на формулировки промптов, тексты интерфейса и маркетинг — учитывать при генерации любого пользовательского текста.

## MCP-серверы (`.mcp.json`)

Подключены: `desktop-commander`, `@magicuidesign/mcp` (UI-компоненты Magic UI — использовать для привлекательного лендинга/дашборда), `playwright` (e2e и парсинг), `context7` (актуальные доки библиотек), `memory`, `serena` (семантическая навигация по коду, проект уже указан), `sequential-thinking`, `package-version`, `mcp-compass`, `nx-mcp` (заготовка под Nx-монорепо), `openrouter` (LLM-роутер).

⚠️ В `.mcp.json` захардкожены API-ключи (context7, openrouter). До первого `git init`/коммита: вынести ключи в env-переменные и добавить `.mcp.json` в `.gitignore` (или хранить в нём только ссылки на `${ENV_VAR}`). Ключи, уже попавшие в этот файл, считать скомпрометированными при любой публикации репо — перевыпустить.
