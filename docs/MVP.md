# MVP-скоуп и стек

Статус: утверждается. Допущения: соло-разработка с Claude Code, минимальный бюджет, хостинг в РФ.

## Цель MVP

Проверить одну гипотезу: **готовы ли люди платить за ИИ-объяснение происходящего на рынке РФ применительно к их бумагам**. Всё, что не проверяет эту гипотезу, — за скоупом.

## Скоуп MVP (входит)

| # | Фича | Суть |
|---|------|------|
| 1 | Утренний дайджест рынка | Автогенерация к 9:00 МСК: ставка/валюта/индекс, главные события и какие бумаги задевают. Публикуется в открытый Telegram-канал (маркетинг) и на сайте |
| 2 | Карточка бумаги | Котировка (MOEX, задержка 15 мин), график, дивиденды, лента событий по эмитенту с ИИ-аннотацией «что это значит» |
| 3 | Watchlist + персональный дайджест | Пользователь отмечает свои бумаги → получает дайджест только по ним (web + Telegram-бот). **Это платная фича — ядро монетизации** |
| 4 | Сигналы «сильных игроков» v1 | Парсинг e-disclosure.ru: существенные факты, сделки инсайдеров/мажоритариев, решения о дивидендах. Лента сигналов с ИИ-пояснением |
| 5 | ИИ-чат | Вопросы на русском по рынку/бумаге, RAG по собранным событиям, ответы со ссылками на источники. Лимиты: N вопросов/день на тарифе |
| 6 | Auth + платёжка | Вход через Telegram Login + email. Free: общий дайджест, карточки. Paid (~490–990 ₽/мес): watchlist-дайджест, сигналы, чат. Оплата ЮKassa |

Каждый ИИ-вывод — с дисклеймером «не является индивидуальной инвестиционной рекомендацией» (см. CLAUDE.md, юридический блок).

## Не входит в MVP

Интеграция брокерских счетов, портфельная аналитика, автоследование, мобильное приложение (PWA-обёртка — после PMF), реалтайм-котировки, технический анализ/прогнозы цен, акции США/Гонконга.

## Стек

### Архитектура: два сервиса + Postgres

```
[Next.js app]  ←→  [PostgreSQL + pgvector]  ←→  [Python worker]
 фронт, auth,         единая БД                 сборщики данных,
 API, биллинг                                   генерация дайджестов,
      │                                         RAG-индексация
      └────────── REST (внутр.) ────────────────┘  + Telegram-бот
```

- **Фронт + продуктовый бэк: Next.js 15 (App Router), TypeScript, Tailwind, shadcn/ui + Magic UI** (MCP уже подключён). SSR обязателен: дайджесты и карточки бумаг — SEO-контент, основной бесплатный канал привлечения.
- **Data/AI-слой: Python 3.12 + FastAPI** (внутренний API) + **APScheduler** (cron-задачи: сбор MOEX/ЦБ/e-disclosure, генерация дайджестов). Python неизбежен из-за экосистемы парсинга и LLM — не пытаться тащить это в Node.
- **БД: PostgreSQL 16 + pgvector** — и реляционка, и вектора для RAG в одном инстансе. Без Redis/очередей в MVP (APScheduler + таблица заданий достаточно).
- **LLM: через OpenRouter** (ключ уже есть, работает из РФ-инфры). Маршрутизация по стоимости: дайджесты/аннотации — дешёвая модель (DeepSeek/Gemini Flash-класс), чат — средняя (Claude Sonnet-класс). Промпт-логику держать в отдельных версионируемых файлах.
- **Embeddings: bge-m3 локально** (sentence-transformers, CPU достаточно) — мультиязычная, сильна на русском, бесплатна. OpenRouter эмбеддинги не отдаёт.
- **Telegram: aiogram 3** в worker-сервисе — бот (персональные дайджесты, нотификации) + автопостинг в открытый канал.
- **Хостинг: Timeweb Cloud VPS, Docker Compose** (next, api, worker, postgres, caddy). РФ-хостинг обязателен: 152-ФЗ (ПДн граждан РФ) + оплата без зарубежных карт. Caddy — TLS из коробки.
- **Платежи: ЮKassa**. ⚠️ Требует юрлицо/ИП/самозанятость — оформить до запуска платного тарифа, на самозанятости можно стартовать.
- **Аналитика: Яндекс Метрика** + события в собственную БД (хватит для MVP).

### Почему не альтернативы

- *Всё на Next.js (без Python):* парсинг e-disclosure, scheduling и LLM-пайплайны в Node — постоянное трение; экосистема data-инструментов в Python на порядок богаче.
- *Всё на Python (Django + HTMX):* продукт продаётся «лицом» — интерактивный дашборд и качественный лендинг на Magic UI/shadcn быстрее и лучше получаются в React.
- *Supabase/Vercel/managed-облака:* оплата из РФ ненадёжна, латентность до РФ-пользователей, риск блокировок — self-hosted на Timeweb предсказуемее.

## Этапы

**Этап 0 — контент-движок (нед. 1–2).** Postgres-схема; сборщики MOEX ISS, ЦБ, e-disclosure; генератор дайджеста; автопостинг в Telegram-канал. *Выход: канал публикует дайджест без участия человека.* Это сразу и проверка качества ИИ-контента, и начало набора аудитории — до единой строчки фронта.

**Этап 1 — web (нед. 3–6).** Next.js: лендинг, дайджест-страницы (SEO), карточки бумаг, auth (Telegram Login), watchlist, персональный дайджест в боте. *Выход: бесплатный продукт онлайн.*

**Этап 2 — монетизация (нед. 7–10).** Лента сигналов e-disclosure, ИИ-чат с RAG, тарифы + ЮKassa, лимиты. *Выход: можно платить.*

**Критерии успеха (3 мес. после запуска):** ≥1000 подписчиков канала, ≥30% открываемость персональных дайджестов, ≥2% конверсия free→paid. Если конверсия не идёт — пересматривать ценность платного тарифа (вероятный кандидат на усиление: сигналы инсайдеров глубже, портфельный анализ).

## Открытые вопросы

- Юрформа для ЮKassa (самозанятость достаточна для старта?).
- ToS-границы парсинга Смартлаба/Пульса — в MVP не трогаем, источник «сильных игроков» только e-disclosure.
- Название/домен (.ru), брендинг.
